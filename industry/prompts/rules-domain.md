【财经审计领域翻译与用词规则 — 本平台内容集中在资本市场、财经与审计会计，严格遵守】

1. 歧义默认值：以下词在中文有别的含义，**一律按财经/审计含义处理**：
   - Audit = 审计（不译“稽核”“审核”）；Auditor = 会计师/审计师，报告中用“审计师”
   - Opinion（审计语境）= 审计意见（无保留意见 / 保留意见 / 否定意见 / 无法表示意见），不译“观点”
   - Material / Materiality = 重大 / 重要性水平（不译“材料”“物质”）
   - Engagement = 审计业务约定/项目（不译“订婚”“参与”）
   - Review（财务语境）= 审阅；Assurance = 鉴证
   - Provision = 预计负债/计提（银行语境为“拨备”），按上下文择一，不译“条款”
   - Reservation = 保留（意见），不译“预订”
   - Listing = 上市/挂牌；Sponsor = 保荐机构/保荐人；Underwriter = 承销商
   - Filing = （向监管）申报/备案文件；Prospectus = 招股说明书
   - Restatement = 财务重述；Impairment = 减值；Goodwill = 商誉
   - Going concern = 持续经营（能力）；Internal control = 内部控制
   - Related party = 关联方；Tunneling = 资金占用/利益输送
   - Bond = 债券（不译“绑定”）；Share = 股份；Equity = 股权/权益
   - Bull / Bear = 看多/看空（或用“牛市/熊市”）；Long / Short = 做多/做空

2. 以下专有名词与缩写**一律保留原文**，不翻译不加中文括注：
   - 监管与机构缩写：IPO / A股 / H股 / A+H / QFII / RQFII / QDII / ETF / REITs / LPR / MLF / OMO / CPI / PPI / PMI / GDP / M0-M2 / 社融 / SDR
   - 会计与审计准则缩写：CAS（企业会计准则）/ IFRS / IAS / US GAAP / ISA（国际审计准则）/ SOX / PCAOB / ACCA / CPA
   - 财务与估值缩写：EBITDA / EBIT / PE / PB / PS / ROE / ROA / ROIC / EPS / NAV / IRR / DCF / WACC / VaR
   - 评级与调整：AAA / AA+ / 上调 / 下调 / 展望稳定 / 列入观察名单
   - 交易与市场：涨停 / 跌停 / 停牌 / 复牌 / ST / *ST / 退市整理期 / 两融 / 北向资金
   - 机构与交易所：证监会 / 上交所 / 深交所 / 北交所 / 新三板 / 中注协 / 财政部 / 中国人民银行 / 金融监管总局 / 国家外汇管理局
   - 通用缩写：Q1–Q4 / H1 / H2 / YoY / QoQ / MoM / TTM / YTD

3. 数字、比例、金额与日期 **一字不改**保留原文：
   - 金额保留原币种与单位（10 亿元 / 3.5 亿美元 / 2,300 万元），不要改成“数十亿”“约两千多万”这类模糊说法
   - 百分比、基点（bp）、倍数、区间原样保留（营收同比增长 12.3% / 上调 25bp）
   - 不要替原文换算币种或调整口径；原文写的是预估、快报还是正式财报，必须照写
   - 公司名、股票简称、股票代码、文件编号（如“证监许可〔2026〕xx 号”）保留原样

4. 谨慎用词，不得替原文拔高：
   - “涉嫌”“拟”“立案调查”“问询”与“已处罚”“已认定”是不同阶段，必须照原文写，不得升级
   - 未经监管认定的财务问题只能写“被质疑”“被举报”“被出具保留意见”，不得写成“造假已被查实”
   - 传闻、预期、市场消息写清来源性质（有市场消息称、据知情人士），不得写成既成事实
