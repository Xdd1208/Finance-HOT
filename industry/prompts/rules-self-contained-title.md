
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 公司名（含股票简称）/ 文件或产品名称。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 编号 / 没信息量的 teaser（如 "〔2026〕45 号"、"最新公告"、"重磅"）时，结合【来源】和正文把主体补进标题。例：原标题 "关于对 XX 采取出具警示函措施的决定" + 来源 "证监会" → "证监会就某事项对 XX 出具警示函"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体主体时，用上位词（如"某会计师事务所"、"某拟上市公司"）兜底，绝不凭"行业常识"编一个具体公司名 / 股票代码 / 金额。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析或评论标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的事实、处罚或新数据，就改写成“发布 / 推出 / 宣布”。只有原标题明确宣布了发布、处罚、受理或决定，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、公司或文件名称。
   例：原标题 "How auditors spot revenue fraud" → "审计师如何识别收入舞弊"，不能写成 "某事务所发布舞弊识别方法"。
